# Support

This is the organisation-wide default; a repository's own `SUPPORT.md` overrides it.

- **Questions and ideas** → Discussions on
  [chock](https://github.com/open-coder-ai/chock/discussions),
  [chock-catalog](https://github.com/open-coder-ai/chock-catalog/discussions) or
  [context-report](https://github.com/open-coder-ai/context-report/discussions), whichever
  owns the thing you are asking about. Telling us what is confusing is a contribution.
- **Bugs** → an issue on the repository that owns the source, with a reproduction. The
  four generated plugin distributions point you to the catalog for policy content and to
  the framework for packaging; the demo repositories point you to the framework.
- **Security vulnerabilities** → a private advisory, never a public issue. See
  [SECURITY.md](SECURITY.md).
- **Docs** → each repository's `README.md` and `docs/` folder. The organisation page at
  https://github.com/open-coder-ai lists every repository with its role and first command.

There is no paid support or SLA; this is open source. Maintainers aim to give first
feedback on issues and pull requests within a few days.
